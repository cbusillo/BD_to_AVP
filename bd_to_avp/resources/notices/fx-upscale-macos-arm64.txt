fx-upscale macOS arm64 binary

BD_to_AVP packages fx-upscale as a separate command-line executable. It upscales
each eye with MetalFX on the generated MV-HEVC route, using the
`--bitrate-scaling-factor` option to apply the app's quality setting.

Vendored binary source:
- Project: fx-upscale by Finnvoor, https://github.com/finnvoor/fx-upscale
- Source: https://github.com/cbusillo/fx-upscale, a fork of
  https://github.com/Netruk44/fx-upscale whose `auto-bitrate` branch adds the
  bitrate options BD_to_AVP uses
- Source commit and build toolchain: `fx-upscale-build.json`
- Platform: macOS arm64 executable linked only to macOS system libraries

fx-upscale is dedicated to the public domain under CC0 1.0 Universal; the text
is in `fx-upscale-LICENSE.txt`.

The build script is `scripts/build_swift_tool_macos.py fx-upscale`. It reads
`fx-upscale-build.json`, verifies the pinned Xcode and SDK, builds the pinned
commit from a clean checkout with path-independent flags, verifies arm64,
system-only linkage and the minimum macOS version, and checks the recorded
checksum before installing the executable into `bd_to_avp/bin`.
