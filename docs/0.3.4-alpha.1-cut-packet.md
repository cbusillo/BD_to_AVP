This is the first production Alpha and the first candidate of the 0.3.4 cycle.
It goes to a few testers. Since Stable 0.3.3 it adds watch folders, including
the MakeMKV handoff that waits for MakeMKV to finish a title; run times that
pause the queue outside chosen hours, on battery, or while the Mac is hot; and
an optional Sleep or Shut Down after the queue finishes. A disc image picked as
its mounted volume is read from its image file, and an incomplete image gets a
warning. When MakeMKV crashes while reading a source, the app says so and
names the known MakeMKV 2.0 bug; testers should use MakeMKV 1.18.4 with a
registration key until MakeMKV fixes it.

The bundled edge264 splitter is pinned to upstream `jens-duttke/edge264-mvc`
tag `v2026.10.17` (`272694e4ca7a7309176c03394e1da8e9fc612af8`), which contains
this repository's fix for the multithreaded worker shutdown assertion (#959).
Its damaged fixture ran 12,000 times multithreaded without an abort, and the
real-MVC integration lane passed 20 of 20 runs.

Sleep and Shut Down were exercised by hand on a `publish-current` build. The
macOS Automation permission that Shut Down needs is bound to the code
signature, so the Director checks Shut Down once more on the signed Alpha.

Post-dispatch source SHA, signed DMG and app-tree checksums, release run, release
ID and appcast checksum remain unset in preregistration. Record those facts only
from the guarded release's immutable receipts.
